# Visit Taniti — D479 prototype

A static, responsive student UX prototype for a fictional tourism destination. It follows the Home and Dining wireframes and adds interactive paths for places to stay, activities, transportation, and visitor information. Bookings are demonstrations only; the site does not collect payment or send form data.

## Run locally

Open `index.html` in a browser, or serve the folder with `python3 -m http.server 8000` and visit `http://localhost:8000/`.

## Proposed Task 2 usability tasks

1. Starting on the homepage, find out how many Taniti restaurants serve American-style food.
2. Find the hours that public buses operate in Taniti City.
3. Find which currencies visitors can use on Taniti.
4. Starting on the homepage, find a family hotel and reach the demo booking confirmation for a party of four.
5. Find the volcano visit activity and reach its demo booking confirmation.

Photo-source links, the course-provided *About the Island* acknowledgment, and the fictional-prototype disclosure are on the dedicated [About & Credits](sources.html) page, linked from every footer.
